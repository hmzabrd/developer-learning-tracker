About

Developer Learning Path Tracker v1.0

A simple, beginner-friendly tool for tracking your programming learning journey. Built with vanilla HTML, CSS, and JavaScript.

Features:

  • Track progress on 45 programming topics across 3 paths
  • Save and organize code snippets
  • View your learning activity with a visual activity grid
  • Export and import your data for backup
  • Dark mode support
  • Mobile-friendly responsive design
